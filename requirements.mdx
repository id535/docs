NinjaHackz is a GPU overlay for Counter-Strike 2 on Windows. Check this list before you buy. The overlay does not attach in exclusive fullscreen.

## Supported setup

- Windows 10 or Windows 11, 64-bit
- Counter-Strike 2
- A GPU that can draw an overlay
- Internet connection for license **Validate**, heartbeat, and updates
- Administrator permission if Windows asks for it

## Display mode

Set CS2 to **Windowed** or **Fullscreen Windowed**. Exclusive fullscreen is not supported. The app shows a banner if CS2 is in exclusive fullscreen. See [Display mode](/troubleshooting/display-mode).

## Hardware-accelerated GPU scheduling

Disable **Hardware-accelerated GPU scheduling (HAGS)** if the overlay feels laggy. Follow [Fix overlay lag (HAGS)](/troubleshooting/hags).

## Anti-cheat software

Close FACEIT and similar anti-cheat before you run NinjaHackz. If attach fails with **Access denied. Close anti-cheat software (e.g. FACEIT) and retry.**, close that software and try again. See [Anti-cheat](/troubleshooting/anti-cheat).

## In-game menu

The menu default key is **N**. Change it under **Extras** → **Menu Toggle Key**.
