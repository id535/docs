You download NinjaHackz from your [account dashboard](https://ninjahackz.com/dashboard/) after purchase. The app is a portable Windows `.exe`. If the dashboard file is a zip, unzip it, then run the `.exe`. Updates also come from the dashboard.

## Where to download

<Tabs>
  <Tab title="Account dashboard">
    After payment you are redirected to the dashboard. Use **Downloads** to get NinjaHackz. This download does not expire. Use **My Account** in the site header to return later.
  </Tab>
  <Tab title="Confirmation email">
    A confirmation email arrives within seconds of payment. It includes a download link and your license key. That email download link expires after 3 days. After that, use the dashboard.
  </Tab>
</Tabs>

## First run

<Steps>
  <Step title="Download from the dashboard">
    Open the [account dashboard](https://ninjahackz.com/dashboard/). Download NinjaHackz from **Downloads**. If this is your first purchase, set a password when the dashboard prompts you.
  </Step>
  <Step title="Unzip if needed, then run the exe">
    If the file is a zip, unzip it first. Run the NinjaHackz `.exe`. Windows may ask for administrator permission. Allow it if you are prompted. This is a portable app, not a traditional installer with a license-agreement wizard.
  </Step>
  <Step title="Validate your license">
    When the app shows **Enter your license key**, paste the key from the dashboard or email and click **Validate**. See [License keys](/license-keys).
  </Step>
  <Step title="Check for updates">
    Stay online. The app checks for updates after Validate. If a newer build is available, download it from the [account dashboard](https://ninjahackz.com/dashboard/) and run that `.exe` instead. See [In-app updates](/troubleshooting/in-app-updates).
  </Step>
  <Step title="Launch CS2">
    Set CS2 to **Windowed** or **Fullscreen Windowed**. Exclusive fullscreen is not supported. When the app shows **Looking for CS2** / **Launch CS2**, start CS2 on Steam (app 730). The overlay attaches when the game is running.
  </Step>
</Steps>

<Tip>
  Open the menu with **N** by default. Change **Menu Toggle Key** under **Extras** if you want a different bind. See [Using NinjaHackz](/using/overview).
</Tip>

## If the email link expired

<AccordionGroup>
  <Accordion title="How to download again">
    1. Open [ninjahackz.com/dashboard](https://ninjahackz.com/dashboard/).
    2. Log in with **Username or Email**, then **Next**.
    3. Open **Downloads** and download NinjaHackz again.
  </Accordion>

  <Accordion title="You cannot log in">
    Use **Forgot password** on the login page. If you never set a password, open the dashboard after purchase and set one when prompted.
  </Accordion>

  <Accordion title="No confirmation email">
    Check spam. Then use the dashboard anyway. The download and license key are there even if the email did not arrive.
  </Accordion>
</AccordionGroup>

<Warning>
  Do not share your download or license key. The license is one activation on one device. See [License keys](/license-keys).
</Warning>
