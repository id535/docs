After you **Validate** and CS2 is running, NinjaHackz draws an overlay. Open the menu, set display mode correctly, then configure each tab.

## How to open the menu

Press **N** to open or close the menu. That is the default **Menu Toggle Key**. Change it on **Extras**.

## Display mode

Use **Windowed** or **Fullscreen Windowed** in CS2. Exclusive fullscreen is not supported. If you see an in-app banner about fullscreen, switch modes. See [Display mode](/troubleshooting/display-mode).
