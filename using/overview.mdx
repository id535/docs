After you **Validate** and CS2 is running, NinjaHackz draws an overlay. Open the menu, set display mode correctly, then configure each tab.

## How to open the menu

Press **N** to open or close the menu. That is the default **Menu Toggle Key**. Change it on **Extras**.

Feature tabs sit in the sidebar. **Config** and **Account** are separate pages.

## Display mode

Use **Windowed** or **Fullscreen Windowed** in CS2 for the best experience. Exclusive fullscreen is supported but not recommended. If you see an in-app banner about fullscreen, switch modes. See [Display mode](/troubleshooting/display-mode).

## Account

Open **Account** in the menu for license status, masked key, activations, and **Plan** (for example **Lifetime** or **Monthly**). There is no **Renews** row. Use **Dashboard** and **Billing** links for the website account. The Help card also opens Documentation, Troubleshooting, Contact support, and **Leave a review**. See [License keys](/license-keys) and [Plans and billing](/subscription-and-billing).

<Tip>
  Stay online. The license heartbeat needs a connection. Failed heartbeats can shut the app down.
</Tip>
