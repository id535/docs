# NinjaHackz CS2 Cheats Changelog: Latest Updates

<Update label="2026-07-10" tags={["Feature","Update"]} description="v5.5.0">
  ## v5.5.0 — Fortnite-style aim assist with magnetism and stickiness

  Aim Assist now has magnetism and stickiness so it locks and stays on target better.

  ### New

  - **Magnetism** — Pulls your crosshair toward the target bone from anywhere inside your aim bubble
  - **Stickiness** — Lock-on only when on the hitbox, with friction, residual slam corrections, velocity following, and smart breakout resistance
  - New settings for magnetism strength, stickiness friction, and aim bubble radius, in per-weapon profiles

  ### Updates

  - Refreshed Aim Assist UI for the new controls
  - Per-weapon and per-class profiles now include magnetism and stickiness
  - Better legitbot integration and aim responsiveness
  - Config and UI cleanups
</Update>

<Update label="2026-07-09" tags={["Update"]} description="v5.4.3">
  ## v5.4.3 — Bone, aim punch, and bomb timer restoration after CS2 update

  Restores function after CS2 patch build 24122613.

  ### Bug fixes

  - **Bone/ESP skeletons** — Bone data reading fixed after skeleton layout changes. ESP and aim assist targeting are stable again
  - **Aim punch / RCS** — Aim punch cache read from the correct services path again
  - **Bomb timer** — Planted C4 detection and timer logic reworked. Timer stops on defuse or explode, shows remaining time, and does not linger after the bomb is gone
  - More robust planted-bomb detection across memory layouts

  ### Updates

  - Updated offsets, button bindings, and schema for the current CS2 build
  - Stability and compatibility fixes after the game update
</Update>

<Update label="2026-05-19" tags={["Feature","Update"]} description="v5.4.0">
  ## v5.4.0 — Aim assist modernization, new sounds, and radar improvements

  Aim assist is more reliable, there is a larger custom sound set, and radar plus bomb timer get polish.

  ### New

  - **Custom hit and kill sounds** — Larger collection of hit and kill sounds
  - **Priority targeting** — Smarter target priority for aim assist
  - **Target stickiness** — Once locked, stays on target through movement and brief obstructions
  - **Velocity prediction** — 80ms lead on strafing targets
  - **Bomb radar icons** — C4 indicators for planted, dropped, and carrier

  ### Updates

  - Aim assist is hold-based only (legacy toggle/always modes removed). Dynamic smoothing by angular speed. Better AimBot + RCS coordination. Retuned per-weapon values
  - TraceShape visibility system temporarily removed (it caused instability)
  - **Per-monitor DPI awareness** — Menus and overlays scale correctly on Windows display scaling

  ### Bug fixes

  - Stability fixes
  - Responsiveness and edge-case fixes across aim, ESP, and radar
  - Cleaner UI spacing and layout

  Download the latest build from your [account dashboard](/download-and-setup).
</Update>

<Update label="2026-05-01" tags={["Feature","Update"]} description="v5.2.0">
  ## v5.2.0 — Per-weapon aim profiles and config system

  Per-weapon and per-class aim profiles for FOV, smoothness, and RCS strength. Aim Assist UI rebuilt around this.

  ### New

  - **Per-weapon and per-class aim profiles** — Outer FOV, Inner FOV, Smooth Factor, and RCS strength per class or per weapon. Tabbed editor: Global, By Class, By Weapon
  - **Global aim profile fallback** — Applies when no class or weapon override exists
  - **Config save/load for profiles** — Profiles save with your config. Existing configs migrate on first load

  ### Updates

  - Rebuilt Aim Assist UI around the profile system. Legacy global aimbot sliders removed
  - RCS strength is part of each profile, not a separate global setting
  - Updated game offsets and button bindings for the current CS2 build
  - Switching profile tabs resets UI state so stale values do not carry over
</Update>

  ## v5.0.0 — Major release

  Revamped interface, better aim assist, improved overlay behavior, and performance gains.

  ### New

  - **Redesigned aim assist UI** — Hitbox visualization and spray pattern preview
  - **ESP preview in visuals** — Live preview of your ESP config on the visuals page
