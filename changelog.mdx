<Update label="2026-09-23" tags={["Feature","Update"]} description="v5.7.1">
  ## v5.7.1 — Rush Hour compatibility, carried-item chams & menu scale

  This release restores the overlay after the 23 Sep CS2 Rush Hour build, adds **Carried Items** chams for held weapons and gear, and fixes menu scale so the whole settings UI resizes cleanly.

  ### New features

  - **Carried Items chams** — On the Beta page, paint held weapons, grenades, and the C4 with their own colour. Carried weapons draw through walls in the item colour (not through smoke).

  ### Updates

  - **Rush Hour offsets** — Refreshed game offsets and signatures so the overlay, chams, and TraceShape work with the 23 Sep CS2 build.
  - **Menu UI Scale** — Scaling now applies to the sidebar, rows, controls, padding, fonts, and in-menu previews together, without flicker while you drag the slider. ESP text and screen-anchored HUD cards stay at screen size.
  - **Launch CS2** — Launching from the loader starts CS2 with your own Steam launch options.
  - Menu polish: clearer sidebar labels, sharper crosshair preview snap, and closing the menu when you click outside is on by default.
  - Out-of-range saved values for aim FOV, sound volumes, crosshair size, radar numerics, UI scale, max render FPS, and pause after kill now snap into the menu ranges when a config loads.

  ### Bug fixes

  - **TraceShape through grates** — Players behind grates, scaffolds, chain-link, and similar see-through brushes now count as visible again for TraceShape ESP and aim checks.
  - Fixed a crash when chams painted held items.
  - Spectator gear is no longer painted when you are watching someone else.

  Download the latest build from your [account dashboard](https://ninjahackz.com/dashboard/).
</Update>

<Update label="2026-09-21" tags={["Feature","Update"]} description="v5.7.0">
  ## v5.7.0 — Kit-aware defuse timer, Neutral menu & TraceShape return

  This release adds a kit-aware defuse countdown under the bomb bar, ships the Neutral overlay menu, and **reintroduces TraceShape** (removed in an earlier release for stability), with settings that persist safely across launches.

  ### New features

  - **Kit-aware defuse timer** — When the bomb is being defused, a countdown under the bomb bar shows how long the defuse will take with or without a kit.
  - **TraceShape** — Reintroduced TraceShape visibility after it was temporarily removed in a previous version. Optional smoke blocking treats active smoke as a line-of-sight blocker when TraceShape visibility is on.
  - **Neutral overlay menu** — Rebuilt settings UI with clearer cards, quieter chrome, a separate Config page, and Account Plan (Lifetime/Monthly) without a Renews row.

  ### Updates

  - **Wall-Hack Range** — Visuals range control renamed from Render Range. Your saved distance still applies.
  - **Beta settings persistence** — Beta chams and TraceShape now save across clean exits. If CS2 or NinjaHackz exits uncleanly while they were on, they start off next launch (safe-off).
  - TraceShape visibility ignores debris for cleaner player visibility through clutter.
  - Menu polish: even setting rows, full-card hover, quieter loading spinner, and clearer Account links.

  ### Bug fixes

  - **Chams flicker** — Fixed visible/occluded color flashing when multiple draws overlapped.
  - Fixed a case where a saved Wall-Hack Range of 30 m could load as a much larger distance.

  Download the latest build from your [account dashboard](https://ninjahackz.com/dashboard/).
</Update>

<Update label="2026-07-10" tags={["Feature","Update"]} description="v5.5.0">
  ## v5.5.0 — Fortnite-style aim assist with magnetism & stickiness

  Major aim assist upgrade introducing magnetism and advanced stickiness for more natural, sticky, and effective tracking.

  ### New features

  - **Magnetism** — Automatically pulls your crosshair toward the target bone from anywhere within your configurable aim bubble for faster target acquisition.
  - **Stickiness** — Smart lock-on that activates only when on the hitbox, with friction to slow your movement, residual slam corrections, and velocity following to stay on moving targets. Includes smart breakout resistance.
  - New aim assist settings for magnetism strength, stickiness friction, and aim bubble radius — fully integrated into per-weapon profiles.

  ### Updates

  - Completely refreshed Aim Assist UI with new controls, better organization, and enhanced widgets for the new mechanics.
  - Expanded per-weapon and per-class aim profiles to include magnetism and stickiness tuning.
  - Improved legitbot integration and overall aim responsiveness.
  - Various refinements to config system and UI components for smoother experience.
</Update>

<Update label="2026-05-01" tags={["Feature","Update"]} description="v5.2.0">
  ## v5.2.0 — Per-weapon aim profiles and config system

  This release introduces a full per-weapon and per-class aim profile system, giving you fine-grained control over FOV, smoothness, and RCS strength for every weapon in CS2. The aim assist UI has been rebuilt around this new system.

  ### New features

  - **Per-weapon and per-class aim profiles** — Aim Assist settings (Outer FOV, Inner FOV, Smooth Factor, and RCS strength) are now configured independently per weapon class (rifles, SMGs, snipers, pistols, etc.) or per individual weapon. A tabbed profile editor in the Aim Assist page lets you switch between Global, By Class, and By Weapon modes.
  - **Global aim profile fallback** — A global profile applies to any weapon not covered by a class or weapon-specific override, so you always have a sensible baseline without configuring every weapon individually.
  - **Config save/load for profiles** — All aim profiles are persisted to and restored from your saved config automatically. Existing configs are migrated to the new format on first load.

  ### Updates

  - **Rebuilt Aim Assist UI** — The aim assist settings page has been redesigned around the new profile system with a tabbed editor and combo row layout. Legacy global aimbot sliders have been replaced.
  - **RCS strength now profile-scoped** — Recoil Control Strength is now part of each aim profile rather than a standalone global setting, so RCS tuning follows your per-weapon or per-class configuration.
  - **Updated game offsets** — Offsets and button bindings have been refreshed for the current CS2 build.
  - **UI state reset on profile switch** — Switching between profile tabs correctly resets UI state to prevent stale values carrying over.
</Update>

<Update label="2026-04-09" tags={["Feature","Release"]} description="v5.0.0">
  ## v5.0.0 — Major release

  This is a major update with a revamped interface, better aim assist, improved overlay behavior, and significant performance gains.

  ### New features

  - **Redesigned aim assist UI** — The aim assist page now includes a hitbox visualization and spray pattern preview, making it easier to fine-tune your settings.
  - **ESP preview in visuals** — You can now see a live preview of your ESP configuration directly in the visuals settings page.
  - **Radar overlay improvements** — The radar is now pixel-perfect with smoother rendering, a new arrow indicator, and tunable sizing options.
  - **Tooltips in aim assist settings** — Hover over any aim assist option to see a short explanation of what it does.

  ### Updates

  - **Smoother aim assist** — Aim smoothing has been reworked for more natural-feeling movement. Default FOV and smoothing values have been adjusted for a better out-of-the-box experience.
  - **Better ESP smoothing** — ESP overlays now render more smoothly with reduced jitter.
  - **Improved overlay in windowed and fullscreen windowed modes** — The cursor now releases properly when opening the menu in windowed or fullscreen windowed mode. A warning displays if you're running in exclusive fullscreen, where cursor release isn't supported.
  - **More reliable CS2 detection** — Attaching to CS2 and detecting your display mode is now faster and more consistent, especially when launching the game after NinjaHackz is already running.
  - **Updated UI styling** — The menu has a refreshed look with a new text logo, improved spacing, and snappier slider controls.
  - **Display mode detection** — NinjaHackz now reads your CS2 display mode from the game config, preventing overlay conflicts and potential freezes.

  ### Bug fixes

  - Fixed a freeze that could occur when the display mode cache refreshed too frequently.
  - Fixed an issue where the overlay could fail to attach on systems with multiple user sessions (e.g., Remote Desktop).
  - Fixed FOV circle rendering being out of sync with the actual in-game view.
</Update>
