If NinjaHackz will not start, closes after you join a match, or the overlay never attaches to CS2, work through this list in order.

## Quick checklist

<Steps>
  <Step title="Run as administrator">
    Right-click the NinjaHackz `.exe` and choose **Run as administrator**. Allow the Windows prompt if it appears. See [Download and setup](/download-and-setup).
  </Step>
  <Step title="Close FACEIT and similar anti-cheat">
    FACEIT-style anti-cheat is not supported while NinjaHackz runs. Fully quit it from the system tray, then start NinjaHackz again. See [Anti-cheat](/troubleshooting/anti-cheat).
  </Step>
  <Step title="Use the latest dashboard build">
    Open the [account dashboard](https://ninjahackz.com/dashboard/), download NinjaHackz from **Downloads**, and run that `.exe`. Do not reuse an old file from email or Discord. See [In-app updates](/troubleshooting/in-app-updates).
  </Step>
  <Step title="Load CS2 fully first">
    Start CS2 and wait until you reach the main menu. Then start NinjaHackz (or restart it) so it can find the game.
  </Step>
  <Step title="Verify CS2 game files">
    In Steam, open **Counter-Strike 2** → **Properties** → **Installed Files** → **Verify integrity of game files**. When Steam finishes, launch CS2 again, then NinjaHackz.
  </Step>
  <Step title="Set a supported display mode">
    Use **Windowed** or **Fullscreen Windowed**. Exclusive fullscreen blocks the overlay. See [Display mode](/troubleshooting/display-mode).
  </Step>
  <Step title="If the overlay feels laggy">
    Disable Hardware-accelerated GPU scheduling (HAGS), then restart Windows. See [Overlay lag (HAGS)](/troubleshooting/hags).
  </Step>
</Steps>

## After a CS2 update

If Aim Assist, Visuals, or Radar stop working right after a CS2 patch, enable **Use Built-in Offsets** and download the newest build. See [After a game update](/troubleshooting/after-a-game-update).

## Crash packages

When NinjaHackz crashes, it can write a package under `%APPDATA%\NinjaHackz\crashes\<guid>\`. The next launch shows a consent prompt:

- **Send** — Opens the local crash folder so you can share files with support. Remote upload is not available yet.
- **Don't send** — Skip this package.
- **Open folder** — Open the package folder in Explorer.
- **Never ask** — Stop showing the prompt for future crashes.

<Note>
  Use **Open folder** or **Send** when support asks for crash files. Attach only what they request.
</Note>

## Still stuck

<AccordionGroup>
  <Accordion title="Access denied / FACEIT">
    Close FACEIT and similar anti-cheat completely, then try again. See [Anti-cheat](/troubleshooting/anti-cheat).
  </Accordion>

  <Accordion title="Offset scan failed">
    Follow [After a game update](/troubleshooting/after-a-game-update), including **Use Built-in Offsets** and a fresh dashboard download.
  </Accordion>

  <Accordion title="Need support">
    Use the in-app copy-info action if it is available. If a crash package prompt appears, use **Open folder** or **Send** to reach the files under `%APPDATA%\NinjaHackz\crashes\`. For logs, see [After a game update](/troubleshooting/after-a-game-update). Contact support through the [support portal](https://ninjahackz.com/support-portal/) with that material and what you already tried.
  </Accordion>
</AccordionGroup>
