NinjaHackz checks for updates after you **Validate**. Get the new file from your [account dashboard](https://ninjahackz.com/dashboard/). Do not download the app from anywhere else.

## How to install an update

<Steps>
  <Step title="Let the app check">
    Stay online after **Validate**. The app shows that it is checking for updates.
  </Step>
  <Step title="Download from the dashboard">
    Open **Downloads** on the [account dashboard](https://ninjahackz.com/dashboard/) and download NinjaHackz. If the file is a zip, unzip it.
  </Step>
  <Step title="Run the new exe">
    Close the old process if it is still running. Run the new portable `.exe`. Click **Validate** if you are prompted.
  </Step>
</Steps>

<Warning>
  The confirmation email download link expires after 3 days. The dashboard download does not expire. Always prefer the dashboard for updates.
</Warning>

<Tip>
  After a CS2 patch, grab the newest dashboard build first. If the overlay still fails, see [After a game update](/troubleshooting/after-a-game-update).
</Tip>
