NinjaHackz cannot attach while FACEIT or similar anti-cheat is running. Close that software, then run NinjaHackz again.

## The error

If you see **Access denied. Close anti-cheat software (e.g. FACEIT) and retry.**, the overlay did not attach.

## How to retry

<Steps>
  <Step title="Close anti-cheat">
    Fully quit FACEIT AC and any similar anti-cheat. Check the system tray so it is not still running in the background.
  </Step>
  <Step title="Run NinjaHackz again">
    Start the portable `.exe` from your [account dashboard](https://ninjahackz.com/dashboard/) download. Click **Validate** if you are prompted.
  </Step>
  <Step title="Launch CS2">
    Use **Windowed** or **Fullscreen Windowed**. Start CS2 (Steam 730) when the app shows **Looking for CS2**.
  </Step>
</Steps>

<Warning>
  Leave FACEIT closed for the whole session. Starting it later can block the overlay again.
</Warning>
