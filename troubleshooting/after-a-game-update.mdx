A CS2 update can change memory offsets. NinjaHackz may fail to scan, and Aim Assist, Visuals, or Radar can stop working until you switch fallback or download a new build.

## If the offset scan fails

<Steps>
  <Step title="Use Built-in Offsets">
    When the app reports a failed scan, enable **Use Built-in Offsets**. That uses the offsets shipped with your current build instead of a live scan.
  </Step>
  <Step title="Download the latest app">
    Open the [account dashboard](https://ninjahackz.com/dashboard/), download NinjaHackz again from **Downloads**, and run that `.exe`. See [In-app updates](/troubleshooting/in-app-updates).
  </Step>
  <Step title="Copy to Clipboard for support">
    If the overlay still fails, use the in-app **Copy to Clipboard** button and paste that text to support.
  </Step>
</Steps>

<Note>
  Beta chams can break after a CS2 update even when other tabs still work. Turn **Beta** off until a new build is on the dashboard. See [Beta](/using/beta).
</Note>

<AccordionGroup>
  <Accordion title="Support asked for logs">
    If support asks for logs, follow the steps they send. Collect only what they request. Do not look for hidden debug tools unless they tell you to.
  </Accordion>

  <Accordion title="You see Failed to get modules address">
    Treat this like a failed offset scan. Enable **Use Built-in Offsets**, download the latest build from the [account dashboard](https://ninjahackz.com/dashboard/), and run that `.exe`. If it still fails, send copy-info to support.
  </Accordion>

</AccordionGroup>
