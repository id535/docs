The NinjaHackz app is not code-signed, so some antivirus tools may flag it. A warning on a file you downloaded from your [account dashboard](https://ninjahackz.com/dashboard/) is usually a false positive.

## What to do

<Steps>
  <Step title="Check where the file came from">
    Only run a NinjaHackz `.exe` that you downloaded from **Downloads** on the [account dashboard](https://ninjahackz.com/dashboard/). Do not run copies from email attachments, Discord, or other sites.
  </Step>
  <Step title="Download a fresh copy">
    If you are unsure about a file, delete it and download NinjaHackz again from the dashboard. If the file is a zip, unzip it, then run the `.exe`. See [Download and setup](/download-and-setup).
  </Step>
  <Step title="Contact support">
    If your antivirus still blocks or removes the file, open a ticket in the [support portal](https://ninjahackz.com/support-portal/). Include the name of your antivirus and the warning it shows.
  </Step>
</Steps>

<Warning>
  Only allow or restore a file in your antivirus if you downloaded it from your account dashboard. If you are not sure, ask support first.
</Warning>
